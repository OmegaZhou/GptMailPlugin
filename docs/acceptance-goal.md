# 当前开发目标与验收要求

2026-10-13：多端、完整安装验收和可用邮箱面板为核心条件。用户允许在 OpenAI 限制下放宽单 ZIP 安装；实际步骤和受限功能必须公开说明。目标进行中，未交付。

## 核心条件

1. 保留原 GptMail 正式插件身份，原条目更新；新名称仅用于安装验收，交付后清理可清理的无关测试插件。
2. 固定托管 HTTPS 服务，Nginx 路径 /mail-mcp；无本地邮箱连接或本地服务，无服务端 /panel。
3. 独立 AuthService 认证服务器账号，宿主持久化 OAuth，新增邮箱无需再次登录服务器。不接受固定服务 API 密钥。
4. ChatGPT 插件面板添加、管理、测试、移除多个邮箱、设置默认邮箱及恢复配置。凭据和 refresh token 服务端加密，不进入模型内容。
5. 必须支持网页、桌面和移动端，不交付桌面专用替代。平台支持、窄屏浏览器测试和真实移动设备验收必须区分。
6. 实现 Google OAuth 登录及自动刷新；QQ 官方授权码；iCloud 应用专用密码。Apple 直接账号授权的项目接入资格未确认，不得冒充已实现。
7. Git 仓库只保留脱敏配置；私有包允许固定真实地址、实例引用、公开 OAuth 配置，不含密码、令牌或邮箱凭据。不为源码脱敏增加中转。
8. 验证清理授权、安装、登录、工具调用、面板、刷新与重启恢复、最终卸载测试插件。验收不发送或删除真实邮件，登录邮件除外。

## 安装方式与限制

个人 ZIP 声明 mcp.json 已真实导入，MCP 被识别，但网页显示“仅限桌面端”，远程 HTTPS 同样受限。只保留为显式 --desktop 调试产物，不是多端交付。

多端候选包引用已有 ChatGPT 云端邮箱服务。导入包后安装或关联服务，再登录 AuthService。如果宿主不自动安装依赖，需在服务插件页单独安装；不得声称 ZIP 创建了云端注册。固定地址在云端注册中维护，实例引用只保存在私有部署配置。

依据：[导入限制](https://learn.chatgpt.com/docs/enterprise/plugin-management#desktop-only-plugins)、[支持的端](https://learn.chatgpt.com/docs/plugins)、[云端发布流程](https://developers.openai.com/plugins/deploy/submission)。个人导入与开发者审核发布不同，不自动改变私人插件发布范围。
