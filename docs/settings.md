# 插件内邮箱管理

首次连接时在 ChatGPT 的自定义 MCP 连接流程填写服务器地址，再到服务器 Authelia 登录页使用管理员创建的用户名和密码授权。ChatGPT 保存服务连接及 OAuth 凭据。之后打开邮箱应用面板自动恢复授权，不再填写服务器地址、密码或服务密钥。

## 使用

在已连接的 **GptMail 邮箱服务** 详情页点击 **打开插件**。面板提供当前服务地址、授权状态、服务连接测试和邮箱管理。原 GptMail 插件引用同一应用连接；当前宿主的原插件详情主按钮仍是“在聊天中试用”，不能将它描述为直接打开面板的按钮。

1. 点击 **添加邮箱**，填写账号 ID、邮箱地址、显示名称及 IMAP/SMTP 参数。QQ、163、126 可快速填写服务器参数。
2. 在密码输入框填写邮箱授权码；收发凭据相同时可点击 **使用相同的收件凭据**。
3. 点击 **测试连接**，确认收件和发件均连接成功，然后 **保存邮箱**。
4. 在同一面板添加、编辑、测试、移除邮箱及选择默认邮箱，不需要为新增邮箱再次 OAuth 授权。

测试仅登录 IMAP/SMTP，不发送邮件。TLS 为隐式加密，STARTTLS 强制升级加密，始终校验证书。编辑时不回显凭据，留空保留旧值；修改服务器、端口、加密或登录账号后必须重新填写凭据。移除仅删除连接，不删除邮箱里的邮件。

服务器地址由宿主在建立连接时保存。面板通过宿主已有的 MCP 连接工作，展示服务器声明的公开地址；此显示值不是用于发现或决定请求目标的配置。更换服务器要重新配置宿主连接，不能仅修改一个面板字段。

## 认证与保存

Authelia 管理服务器账号、授权码及刷新令牌。GptMail 验证签名、issuer、audience、client_id、subject、有效期和权限。仅允许私有配置中的所有者访问。邮箱配置以 AES-256-GCM 加密存储于 `MAIL_STATE_DIR/panel/settings.enc.json`；该历史目录名不是 HTTP 面板。

面板自动调用 `settings_bootstrap` 恢复短期管理会话，会话绑定稳定的已认证所有者。页面重载、访问令牌更新或管理会话过期不需要输入管理密钥。仅服务器明确返回管理会话失效时自动恢复并重试一次；网络错误不能盲目重放写入。

UI 源码位于 `ui/`，MCP `resources/read` 返回内嵌 HTML。没有服务端 `/panel`、独立管理网页或配置 REST API。表单通过 MCP Apps 桥接调用 `ui.visibility:["app"]` 工具，凭据和会话保存在组件内存及工具结果 `_meta`，不写入聊天内容或模型上下文。

## 面板接口

| 工具 | 作用 |
|---|---|
| `open_settings` | 打开内嵌面板 |
| `settings_read` / `settings_update` | 原生设置发现协议，仅声明入口按钮 |
| `settings_bootstrap` | 从当前已授权连接恢复管理会话 |
| `settings_state` / `settings_logout` | 查询状态 / 结束临时面板会话 |
| `settings_save_account` | 添加或更新邮箱 |
| `settings_delete_account` / `settings_default` | 移除连接 / 设置默认邮箱 |
| `settings_test` | 测试已存或待保存的邮箱连接 |

旧 `settings_login` 和 `settings_connection` 已移除，不再输入服务器密钥或导出伪连接配置。
